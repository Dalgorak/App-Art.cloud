Hosting

Die Seite wird über GitHub Pages bereitgestellt, ein Dienst von GitHub, Inc. Beim Aufruf entstehen dort technisch erforderliche Verbindungsdaten, insbesondere IP-Adresse, Datum und Uhrzeit, aufgerufene Adresse und Browserkennung. Das ist nötig, um die Seite auszuliefern. Rechtsgrundlage ist Art. 6 Abs. 1 lit. f DSGVO. Hinweise von GitHub stehen in der Datenschutzerklärung von GitHub.

Darstellung

Der Schalter für helle und dunkle Darstellung speichert die Wahl im lokalen Speicher des Browsers (localStorage, Schlüssel „theme“). Das passiert erst, wenn der Schalter benutzt wird. Es werden keine Daten an einen Server gesendet. Rechtsgrundlage ist § 25 Abs. 2 Nr. 2 TDDDG.

Downloads

Die Installationsdateien liegen bei GitHub Releases. Ein Klick auf „Installieren“ öffnet GitHub. Beim Laden der Seite fragt der Browser die Downloadzahlen bei der GitHub-API ab. Dabei sieht GitHub die IP-Adresse. Es gelten die Datenschutzbedingungen von GitHub.

Unterstützung über PayPal

Der Button „Unterstützen“ öffnet PayPal. Zahlungsdaten werden dort eingegeben und von PayPal verarbeitet, nicht auf dieser Seite. Es gilt die Datenschutzerklärung von PayPal.
